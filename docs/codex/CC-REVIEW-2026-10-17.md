Move the research pack out of git to `/Users/kishimakoto/Documents/RTU/research-outputs/2026-10-17-snobi-codex/`, keeping text findings and dropping or thumbnailing third-party screenshots. These branches are local and unpushed, so a new clean branch is fine; do not rewrite `claude/v2-pages`.
2. **P2: `next.config.ts` runs `python3 scripts/system-registry.py --check` via `execFileSync` on every Next process** (build, dev, start).
   - It makes python3 a hard dependency of `next start` and of any build host. The check belongs in the build script, not the framework config.
   - **Action:** move it to a `prebuild`/`cf:build` step (e.g. `"cf:build": "python3 scripts/system-registry.py --check && …"`). Keep the check; don't weaken it.
3. **P2: sync duplicates.**
   - 26 `* 2.*` files in the worktree, and git reports `garbage found … 2` inside `.git/objects` and `.git/worktrees`.
   - `~/Documents` is iCloud-Drive-synced (file-provider xattr VERIFIED). iCloud is duplicating files inside the git object store.
   - **Action for Codex:** never stage `* 2.*`, and list them in the worklog.
   - **Action for the owner:** move the repos out of iCloud-synced `Documents` (e.g. `~/Code/`), or mark them `.nosync`. This is a corruption risk, and the same mechanism as the 2026-05-13 dataless incident (INFERRED).
4. **P3: `.credit { overflow-wrap: anywhere }`** (supplier-credit reflow).
   - It can break 「写真提供：小川珈琲」 mid-word on narrow cards.
   - **Action:** prefer `overflow-wrap: break-word` plus `word-break: keep-all` for the JP credit, or allow the wrap only before 「写真提供」. Show a 360 px screenshot.
